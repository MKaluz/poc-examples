## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for this repo, and external PRs are also treated as a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Domain docs are configured as single-context (root `CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.
